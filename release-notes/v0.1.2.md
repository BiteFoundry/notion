Leave a page open to see edits to its blocks, comments, title, and icon. The terminal checks the visible page every five seconds by default and checks again when you return to the window. This also picks up nested edits that leave the parent page’s timestamp unchanged.

Profiles with `active_poll_ms = 15000`, the previous default, use the new five-second interval. Other custom intervals are preserved. New pages continue to appear through the workspace refresh.
