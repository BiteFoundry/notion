## What's Changed

### Notion Native Block-Live Flow Editing
- Added direct click-to-edit on any editable Notion text block (`Paragraph`, `Heading 1–3`, `Bulleted/Numbered List`, `To-Do`, `Toggle`, `Callout`, `Quote`, `Code`) directly in place on the rendered canvas, keeping all surrounding blocks rendered while preserving direct clicks on To-Do checkboxes, toggle arrows, child pages/databases, images, and links.
- Added seamless cross-block `↑`/`↓` navigation at block boundaries (optimistically committing the active block and skipping non-editable blocks such as dividers, images, and tables).
- Added natural `Enter` sibling block splitting/creation with 0ms optimistic insertion and coalesced Notion API background sync (`Shift+Enter` inserts a soft newline; `Enter` in code blocks keeps inserting newlines).
- Added live Markdown prefix block-type shortcuts (`# `, `## `, `### `, `- `/`* `, `[] `/`[ ] `, `> `) on `Paragraph` blocks plus `Backspace` at column 0 to revert back to `Paragraph`.
