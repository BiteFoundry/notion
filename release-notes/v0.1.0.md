# `@shinick/notion` v0.1.0 Release Notes

Initial standalone release of `@shinick/notion` (`notion` / `nt`) — a Notion-native Terminal UI, CLI, local HTTP API (`:8791`), and 18-tool stdio MCP server.

## What's New

- **Notion-Native TUI**:
  - Minimal 1-line Breadcrumb Bar (`Workspace ▾ / Parent / 📄 Page`) + `[Width: Centered|Full]` `[Sync]` `[? Help]`
  - Collapsible Workspace Sidebar with **Favorites** (`★`), hierarchical **Workspace Tree**, **Databases**, and **Recent / Trash**
  - **Editorial Page Canvas**: Centered (~88 cols) vs Full width (`w`), colored Notion properties strip, interactive `to_do` checkboxes (`Space`/`x`), live expandable `toggle` blocks, tinted Callouts, bordered Code Blocks, aligned Unicode Tables, inline terminal graphics (Kitty / iTerm2 / Sixel / Halfblock) + HD overlay (`v`), and right-split Comments Peek Drawer (`C`)
  - **Database Views**: live switcher between **Table (`1`)**, **Kanban Board (`2`)** with `h`/`l` navigation & `m` card status move, and **List (`3`)**, plus `f` Filter, `s` Sort, and `n` New Item
  - **Global Overlays**: Quick Find & Command Palette (`Ctrl+K`/`Ctrl+P`), Workspace Switcher (`Ctrl+S`), Settings (`Ctrl+,`, 5 curated palettes), File Picker with zoxide (`Ctrl+F`), Link Extractor (`u`), Context Menu (`.`), and Help (`?`)
- **Authentication & Multi-Workspace**:
  - Internal Integration Token (`notion login --token` / `NOTION_TOKEN`) and Public OAuth 2.0 loopback (`notion login --oauth`)
  - Secure OS keyring storage (`notion-cli`, pure-Rust Linux `zbus` secret service) + `notion workspaces list|use|add|remove`
- **SQLite WAL + FTS5 Cache & IPC Sync Daemon**:
  - Workspace-scoped local cache with automatic Korean `<3` char `LIKE` search fallback
  - Single-instance background sync daemon (`notion daemon start|status|stop|restart`)
- **CLI, HTTP API (`:8791`), and MCP Server (18 Tools)**:
  - Complete CLI (`pages`, `blocks`, `db`, `comments`, `search`, `download`, `workspaces`, `sync`, `serve`, `mcp`, `doctor`, `update`)
  - 6-platform npm packaging (`win32-x64`, `win32-arm64`, `darwin-x64`, `darwin-arm64`, `linux-x64`, `linux-arm64` GLIBC <= 2.28)
