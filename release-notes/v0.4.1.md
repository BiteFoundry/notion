`notion serve` is locked down against browser and DNS-rebinding access. The wildcard CORS layer is gone, requests whose `Host` header is not a loopback name, the bind address or an `--allowed-host` value are refused, and browser requests from origins that were not opted in with `--cors-origin` get `403`. `/api/v1/*` now always needs a key: `--api-key` or `NOTION_SERVE_API_KEY`, else a 32-byte key generated for the run and printed once to stderr. `--allow-keyless` opts out on loopback binds only, a non-loopback `--bind` without a key is refused, and keys are compared in constant time.

Long text no longer fails with HTTP 400: every write path (page and database creation, page and block updates, block appends, comments) splits text spans over Notion's 2,000-unit limit into adjacent spans with the same formatting, counted in UTF-16 units and cut on grapheme boundaries, so the text reads back unchanged. Peek URLs (`?p=`) now target the open row instead of the database, and URLs with a trailing slash or a hyphenated UUID resolve directly.

Behind a TLS-inspecting corporate proxy, the OS trust store is now trusted next to the bundled roots, and extra root certificates are read from `NOTION_EXTRA_CA_PEM` (a path or PEM text), `SSL_CERT_FILE` and `NODE_EXTRA_CA_CERTS`. An `UnknownIssuer` failure carries a hint naming these variables, `notion doctor` lists each CA source, and warnings go to stderr only so MCP stdio stays clean. Verification can only widen; it cannot be turned off.

Workspace handling is safer: environment overrides apply without a config file and are never written back into `config.toml`; a `NOTION_TOKEN` that differs from the saved login gets a cache partition of its own; and switching workspace in the TUI restarts sync on the new workspace's cache instead of writing into the old one.

The TUI database view now says when a database has more rows than it shows (`250+ rows · showing first 250`), and an explicit refresh reads up to 5,000 rows so rows archived in Notion leave the cache. A full workspace rescan is available from MCP `sync_now {"full": true}`, `POST /api/v1/sync?full=true` and the TUI command palette ("Full Resync Workspace").

The HTTP API pages database queries (`cursor` in, `has_more`/`next_cursor` out), and `PATCH /api/v1/pages/{id}` applies every field it is given (`title`, `icon`, `archived`, `properties`) in one Notion call instead of dropping all but the first. After a stale-block failure, a page edit is retried only when nobody else changed the page; otherwise the save stops with "Reload the page before saving." and the CLI keeps the edited text in its recovery file.

Markdown tables typed into the editor or `pages edit --body` become real Notion tables, tables over 100 rows are sent in batches, and table export escapes `|` and line breaks inside cells. Downloaded files keep Korean, Japanese and Chinese names, with control and bidirectional characters, Windows device names and over-long names made safe. MCP tool descriptions now state their request cost.

## Compatibility and migration

| Changed behavior | Before (v0.4.0) | After | Migration for existing callers |
|---|---|---|---|
| `notion serve` without `--api-key` | `/api/v1/*` open on loopback | A key is generated per run and printed once to stderr; requests without it get `401` | Pass `--api-key` (or `NOTION_SERVE_API_KEY`) and send it as `Authorization: Bearer …` or `x-api-key`; or start with `--allow-keyless` on a loopback bind |
| `notion serve --bind <non-loopback>` without a key | Started | Refuses to start | Pass `--api-key` |
| Browser calls to `notion serve` | Any origin (`Access-Control-Allow-Origin: *`) | No CORS headers; cross-origin requests get `403` | Add `--cors-origin <scheme://host[:port]>` for each page origin |
| `Host` header on a loopback `notion serve` | Not checked | Must be a loopback name, the bind address or an `--allowed-host` value, else `403` | Add `--allowed-host <name>` for proxies or custom host names |
| `PATCH /api/v1/pages/{id}` with several fields | Applied only the first of `archived` / `properties` / `title`+`icon` | Applies all of them in one call | None; a body with no field now returns `400` |
| `POST /api/v1/databases/{id}/query` reply | `{ ok, count, rows }` | Adds `has_more`, `next_cursor` | None (additive) |
| `POST /api/v1/sync`, MCP `sync_now` reply | No `full` key | Adds `full`; `?full=true` / `"full": true` rescans | None (additive) |
| Cache directory with `NOTION_TOKEN` set | Shared with the saved login's workspace | Separate `env-<hash>` partition when the token differs from the saved login | The first run with such a token rebuilds its cache; nothing to change when no login is saved or the token is the same |
| Download file names with non-ASCII characters | Replaced with `_` | Kept | Callers matching the old underscored names should use `file_name` / `path` from the reply |
