## What's Changed

### `Ctrl+M` Mode Toggle (Rendered Block-Live WYSIWYG ↔ Markdown Source)
- Wired `Ctrl+M` (`Action::ToggleEditorMode`) and clickable `[Render]` / `[Src]` pills to switch seamlessly between Rendered Block-Live WYSIWYG (`ui.block_editor`) and full-page Markdown Source (`ui.inline_editor`) while preserving edits and positioning the cursor near the active block.
- Updated status bar hints to advertise `Ctrl+M Src` / `Ctrl+M Render`.

### `Esc` Viewport Preservation
- Updated `close_inline_editor_and_flush` and `commit_and_sync_block_editor` to synchronize `selected_block` and enable `canvas_follow_selected` so edited blocks stay visible in the viewport after exiting edit mode.
