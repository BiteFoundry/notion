## What's Changed

### Dynamic Property Surfacing, Selective `fields` Projection & Parser Completeness
- Compact `get_page` now surfaces populated dynamic page/database properties in `omitted.properties` as `[{ "name", "type" }]` instead of a single opaque `"page.properties"` entry.
- Added selective `fields: [...]` projection across MCP `get_page`, CLI `pages get --json --fields`, and HTTP `GET /api/v1/pages/{id}?fields=...` (matching standard fields and case-insensitive property names, with `missing_fields`), skipping live comment/block fetches unless explicitly requested.
- Preserved `files` property URLs, unknown property summaries, additional `rollup` variants, and page-level `created_by` / `last_edited_by` metadata.

### Symlinked `$HOME` & npm Postinstall Hardening
- Fixed `scripts/postinstall.mjs` main-module guard via `fs.realpathSync` for symlinked `$HOME` / npm prefixes.
- Canonicalized daemon UDS hashes and isolated `XDG_RUNTIME_DIR` fallback sockets per profile.
- Preserved dotfile symlinks in `write_atomic` (while refusing `0600` secret symlinks), expanded `~/` on `NOTION_CONFIG_DIR`/`NOTION_DATA_DIR`/`$EDITOR`, and resolved symlinked binaries in `updater.rs`.
