## What's Changed

### Centered ↔ Full Layout Parity & Width-Aware Text Wrapping
- Fixed text clipping when switching between Centered and Full width modes in `notion_view` by migrating paragraphs, tables, callouts, code blocks, and headings to display-width-aware styled span wrapping (`wrap_styled_spans` / `render_wrapped_table`), guaranteeing full text visibility and `line.width() <= avail` across both modes.

### Terminal Image Preview Quality & Protocol Detection
- Replaced fixed low-resolution downsampling and distorted aspect-ratio math with terminal cell-geometry sizing and unified protocol detection across Kitty, iTerm2, Sixel, and half-block renderers.

### Native HTML/SVG/Canvas & Embedded Graphics Rendering
- Eliminated raw HTML/SVG/script source leaks in attachment and HTML previews via pure-Rust `bitefoundry-html` (`resvg 0.50` + `tiny-skia` + `base64`) for inline `<svg>`, `<canvas>`, and `data:image/*` graphics, with an explicit `[o: Browser]` banner for external `<script src>` content.

### Unified Markdown Rendering & `.md` Preview
- Standardized Markdown parsing on `pulldown-cmark 0.13` via `bitefoundry-html::markdown` and enabled direct `.md` attachment previewing.

### TUI Stability, Kanban Safety & Sync Isolation
- Fixed kanban board panic edge cases, isolated database/page view state, improved sync/overlay UX, and added Docker / MCP Registry (`server.json`) packaging.
